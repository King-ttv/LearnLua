Lesson 11 · Roblox Scripting
Script Types
Learn the three main script types in Roblox: Script, LocalScript, and ModuleScript.
Script vs LocalScript

Script (Server Script) runs on the server. It can access player data, datastores, and all game objects. Used for game logic, spawning enemies, etc.

LocalScript runs on the client (each player's computer). It can only access local objects and can't directly access player data. Used for UI, input handling, camera control.

Remember: Never trust the client. Always validate player actions on the server!

💡
Use RemoteEvents and RemoteFunctions to communicate between server and client scripts. This prevents exploiters from modifying game logic.
ModuleScript

A ModuleScript is reusable code that both server and local scripts can load using require(). It's perfect for shared utility functions, math libraries, or game constants.

ModuleScripts don't run automatically — they return a table that you require into other scripts.

RemoteEvents & RemoteFunctions
Communication between server and client is essential for secure, multiplayer games.
RemoteEvent Basics

A RemoteEvent lets the server and clients send messages to each other. Use :FireClient() to send from server to one client, :FireAllClients() for everyone, and :FireServer() from the client.

Always validate input on the server — never trust the client!
