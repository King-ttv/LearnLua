Lesson 1 · Fundamentals
Variables & Data Types
Store and manipulate information in your scripts.

What is a Variable?

A variable is a named container that stores a value. Think of it like a labeled box where you can put data and retrieve it later by name.

In Lua, creating a variable is simple:

example.lua
local name = "Alex" local age = 18 local isPlayer = true print(name) -- Output: Alex
ℹ️
Always use local for variables. It prevents bugs by keeping variables scoped to their block of code.

Lua Data Types

Lua has 8 main data types. Here are the most common ones:

Type Example Description
number 42, 3.14 Integers and decimals
string "hello", 'world' Text data
boolean true, false True or false values
table {1, 2, 3} Arrays and dictionaries
nil nil Empty/no value

Operators
Perform calculations and comparisons with operators.

Arithmetic Operators

Use arithmetic operators to perform math operations:

math.lua
local a = 10 local b = 3 print(a + b) -- 13 print(a - b) -- 7 print(a * b) -- 30 print(a / b) -- 3.333... print(a ^ 2) -- 100 (power) print(a % b) -- 1 (modulo)
Operator Name Example
+ Addition 5 + 3 = 8
- Subtraction 5 - 3 = 2
* Multiplication 5 * 3 = 15
/ Division 6 / 2 = 3
^ Power 2 ^ 3 = 8
% Modulo (remainder) 7 % 3 = 1

Comparison Operators

Compare values to get true or false:

compare.lua
local x = 10 print(x > 5) -- true print(x < 5) -- false print(x == 10) -- true (equal) print(x ~= 5) -- true (not equal) print(x >= 10) -- true print(x <= 10) -- true
⚠️
Important: Use == to compare values, not = (which assigns).

Lesson 3 · Fundamentals
Conditionals (if/else)
Make decisions in your code with if statements.

If Statements

Use if to run code only when a condition is true:

conditional.lua
local age = 16 if age >= 18 then print("You are an adult") end if age < 13 then print("You are a kid") elseif age < 18 then print("You are a teen") -- This runs else print("You are an adult") end
💡
Pro Tip: You can chain multiple elseif conditions together for more complex logic.

Logical Operators

Combine conditions using and, or, and not:

logic.lua
local age = 25 local hasLicense = true if age >= 18 and hasLicense then print("You can drive!") end if age < 18 or not hasLicense then print("You cannot drive") end

Lesson 4 · Fundamentals
Loops
Repeat code multiple times with loops.

For Loops

The for loop runs code a specific number of times:

for_loop.lua
-- Count from 1 to 5 for i = 1, 5 do print(i) -- Prints 1, 2, 3, 4, 5 end -- Count by 2s for i = 0, 10, 2 do print(i) -- Prints 0, 2, 4, 6, 8, 10 end

While Loops

The while loop runs while a condition is true:

while_loop.lua
local count = 1 while count <= 5 do print(count) count = count + 1 -- Don't forget to increment! end
⚠️
Warning: Make sure your while loop condition eventually becomes false, or it will loop forever!

Lesson 5 · Fundamentals
Functions
Create reusable blocks of code.

Defining Functions

A function is a reusable block of code. Define it once, call it many times:

functions.lua
local function greet(name) print("Hello, " .. name) end greet("Alice") -- Output: Hello, Alice greet("Bob") -- Output: Hello, Bob

Return Values

Functions can return values for you to use:

return.lua
local function add(a, b) return a + b end local result = add(5, 3) print(result) -- Output: 8
💡
Pro Tip: Functions can return multiple values separated by commas: return x, y, z

Lesson 6 · Fundamentals
Tables
Work with arrays and dictionaries.

Tables as Arrays

Tables are collections that can store multiple values. Use {} to create them:

arrays.lua
local fruits = {"apple", "banana", "orange"} print(fruits[1]) -- apple (note: 1-indexed!) print(fruits[2]) -- banana print(#fruits) -- 3 (length) -- Add a new item table.insert(fruits, "grape")
⚠️
Important: Lua tables are 1-indexed (start at 1), not 0-indexed like many languages!

Tables as Dictionaries

Use tables like dictionaries with key-value pairs:

dict.lua
local player = { name = "Alex", level = 5, health = 100 } print(player.name) -- Alex print(player["level"]) -- 5 player.health = 75 -- Update value

Lesson 7 · Roblox
Roblox Environment
Understand how Roblox Lua works.

Global Variables

Roblox provides global variables you can access from anywhere:

Variable Description Example
game Root of Roblox instance tree game.Workspace
workspace The 3D world workspace.Part
script The current script object script.Parent
_G Global table (cross-script) _G.myValue = 5

Services

Access Roblox services using game:GetService():

services.lua
local Players = game:GetService("Players") local RunService = game:GetService("RunService") -- Common services: -- Players, Workspace, Debris, UserInputService -- RunService, TweenService, etc.
💡
Pro Tip: Always use :GetService() instead of accessing services directly. It's more reliable!
Lesson 8 · Roblox
Working with Services
Interact with Roblox APIs using services.

Getting Players

The Players service manages all connected players:

players.lua
local Players = game:GetService("Players") -- When a player joins Players.PlayerAdded:Connect(function(player) print(player.Name .. " joined!") end) -- When a player leaves Players.PlayerRemoving:Connect(function(player) print(player.Name .. " left!") end)

Signals & Events

Roblox events trigger when something happens. Use :Connect() to listen:

events.lua
local part = workspace.Part -- When a part is touched part.Touched:Connect(function(hit) print(hit.Name .. " touched the part") end) -- When a part changes parent part.AncestryChanged:Connect(function() print("Part moved!") end)

Lesson 9 · Roblox
Remote Events
Communicate between client and server.

What are Remote Events?

Remote Events let the client (LocalScript) and server (Script) communicate with each other. This is essential for multiplayer games!

ℹ️
Client: LocalScript (runs on player's computer)
Server: Script (runs on Roblox servers)

Firing Events

Send messages from client to server:

LocalScript (Client)
local event = game.ReplicatedStorage:WaitForChild("MyEvent") -- Send data to server event:FireServer("Hello server!", 42)
Script (Server)
local event = Instance.new("RemoteEvent") event.Name = "MyEvent" event.Parent = game.ReplicatedStorage -- Listen for client data event.OnServerEvent:Connect(function(player, message, number) print(player.Name .. ": " .. message) end)
⚠️
Security: Never trust client input! Always validate data on the server before using it.
